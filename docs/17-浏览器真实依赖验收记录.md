  `Qwen3-Embedding-8B`、本地 BGE 重排和 `MiniMax-M2.7`。只读应用在授权前
  检索被拒，授权后页面检索成功；页面成功显示无结果状态。
- 四条手工设计的初步探测中，一条有对应资料的问题返回结果，三条无关问题返回空
  结果；这不是独立的司法业务金标准，不能据此确认阈值适用于其他案件或语料。
  自动标注的一条检索回归样本通过，不代表业务准确率。
- 独立 SQLite 和独立 Worker 进程以真实 Embedding 和 BGE 完成异步索引、反馈及
  坏案例评测回归。另通过独立 Worker 进程测试了排队后权限撤销、凭证撤销及
  权限恢复后的重试；这些撤销测试使用的是测试模型，不等同生产环境验收。
- 全量 `python -m pytest -q` 通过；未配置外部环境的可选测试按测试条件跳过。
- 本次对话中通过最高人民法院官网页面核对了快照来源及发布信息；法律现行效力、
  具体适用性和业务阈值仍需专业人员审核。生成模型测试为手工提供检索片段的
  普通对话调用，并未证明整个系统具备可强制执行的无证据生成拒答。

  `BAAI/bge-reranker-v2-m3` 和远程 `MiniMax-M2.7`，通过真实 Chrome headless
  执行；原 8098 控制台仍是模拟推理实例，不作为真实模型证据。

  `https://www.court.gov.cn/fabu/xiangqing/508001.html`，保留来源、发布时间、
  抓取时间和原始页面哈希，并验证保存文本的哈希。现行效力未复核。
- 通过浏览器发起 API 操作完成资料入库、真实向量索引、审批发布、引用快照回查、
  反馈、技术标注和评测；通过页面表单完成检索；真实生成模型返回了响应。
  审批和标注是隔离环境技术操作，不是法律专业审签。
- 修复长文档重排时 TEI 许可不足导致的 HTTP 429，以及浏览器无损字符串 ID
  无法用于反馈评测数据集的问题。单条技术回归样本 recall@3 为 1，不能据此
  推断业务准确率，也不是独立金标准。

  状态为 `VERIFIED`。这是**验收失败**：该状态仅说明引用可以定位，不证明
  相关性或法律适用性。默认相关性阈值未校准，必须使用独立业务样本、无证据样本

## 2026-11-18 本地重排和真实模型试点

- 下载 `BAAI/bge-reranker-v2-m3` 固定版本 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`，权重 SHA-256 校验通过。本机 Windows 应用控制策略阻止加载 PyTorch，改用 Docker 内的 CPU 推理服务。
- 容器镜像的 AMD64 摘要经官方仓库和镜像站核对一致。服务仅绑定本机，最多使用 4 核和 5 GB 内存；为控制资源，输入超过 512 token 会截断。后端使用近似 GELU，与 Transformers 结果可能有细微差异。
- 项目客户端实际调用远程 `Qwen3-Embedding-8B` 和本地 `bge-reranker-v2-m3` 成功。一次中文两候选样本中，相关文本得分约 0.986，无关文本约 0.000016，重排耗时约 3.25 秒；这不是性能承诺或业务评测。
- 在 pytest 的隔离 SQLite 数据库中，使用上述真实 Embedding 和重排完成文档入库、索引审批发布、授权检索、引用核验、反馈、标注和评测回归。样本为明确标注的技术测试文本，不是法律业务金标准。
- 本次真实模型试点通过应用测试客户端运行，未完成真实浏览器端到端验收，也未验证真实生成模型参与回答。原 8098 控制台仍为模拟模型实例，既有模拟索引不得作为真实模型索引使用。

## 范围和环境

- 在本机 Chrome 的 headless 模式中运行真实页面和 JavaScript，通过 HTTP 调用本机服务。
- 使用公开资料库的 SQLite 在线备份副本和独立对象目录；创建与授权操作只发生在副本中。
- Redis 为本地真实容器；模型设置为 `proxy`，未替换为模拟响应。
- 实际配置的代理 `/models` 返回 HTTP 401，服务就绪探测显示 `inference` 异常。
- 公开资料库的原始索引此前使用模拟向量生成。本次不能以该索引证明真实向量检索质量。

## 已执行

`tests/console_live_browser.cjs` 通过 Chrome 检查控制台连接、各主页面导航、公开
资料库展示、完整长整数 ID 传输、隔离知识库创建、能力创建和发布、限制知识库范围
的授权，以及非法授权范围不提交。该测试需要显式指定隔离的 loopback 实例，且会
创建数据，不应连接正式数据库。

实际代理返回 401 时，检索页面显示失败并隐藏旧结果；新文本入库报告模型错误。
对已存在的公开文档，在隔离副本中重新提交并触发真实索引任务，页面明确报告最近
一次索引执行失败，不额外重复创建手动索引任务。

本次修复了前端对超过 JavaScript 安全整数范围的资源 ID 的处理。浏览器不支持
无损 JSON 数字解析时会报错，不会静默提交被舍入的 ID；无效知识库授权范围会被拒绝。
页面还区分模拟模型和真实模型就绪状态，并按索引任务实际状态展示结果。

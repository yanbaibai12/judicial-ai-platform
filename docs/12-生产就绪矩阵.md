## 上线前必须补齐

1. 在目标环境执行 Milvus、Neo4j、Redis、vLLM 联调与故障注入。
2. 使用真实 IdP/LDAP 验证角色映射、令牌过期与撤销。
3. 完成 MySQL 生产迁移与回滚演练、备份恢复演练。
4. 完成 K8s 滚动升级、PDB、HPA、NetworkPolicy 与 Ingress TLS 验证。
5. 完成压测、安全扫描、镜像签名与 SBOM。
6. JEV 未经合规与中文司法准确率验证前不得切主链路。

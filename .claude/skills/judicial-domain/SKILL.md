# Judicial Domain

## 使用时机
涉及法律术语、法条引用、案例检索、裁判文书、合规话术或评测集设计时。

## 检查清单
- 法条名称、条号、时效性与效力层级是否准确。
- 案号格式、法院层级、裁判类型是否被正确识别。
- 是否把模型生成内容伪装成法律意见或裁判结论。
- 是否保留引用原文、来源、版本和页码。
- 是否对当事人、证人、未成年人等敏感信息脱敏。
- 是否存在地域、层级、时间维度的适用差异。

## 输出
领域术语表、引用校验规则、评测样本说明、合规风险清单。

## 禁止
- 不得编造法条、案号、裁判结果或法院观点。
- 不得以模型置信度替代证据核验。

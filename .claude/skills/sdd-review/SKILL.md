# SDD Review

## 使用时机
代码完成、合并前、上线前。

## 输入
变更 diff、规格、设计、任务清单、测试结果。

## 步骤
1. 逐条核对规格与验收标准。
2. 检查权限绕过、租户越界、注入、敏感信息泄漏与日志。
3. 检查并发、幂等、重试、超时、队列积压与降级。
4. 检查迁移可逆性、契约兼容性与前端错误态。
5. 输出阻断项、建议项与验证证据。

## 输出
`specs/<change-id>/review.md`：结论、阻断项、风险、测试证据。

## 门禁
- P0/P1 安全问题为零。
- 阻断项未关闭不得进入验收。

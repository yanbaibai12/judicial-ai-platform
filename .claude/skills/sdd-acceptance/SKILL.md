# SDD Acceptance

## 使用时机
评审通过，准备交付或上线。

## 输入
规格、设计、评审记录、测试报告、监控与部署清单。

## 步骤
1. 逐条执行验收标准并记录证据。
2. 验证健康检查、监控、告警、备份、恢复与回滚。
3. 检查权限矩阵、默认密钥、CORS、TLS、审计与保留策略。
4. 记录性能、容量、错误预算与已知限制。
5. 写入 `specs/<change-id>/acceptance.md` 和 `docs/12-生产就绪矩阵.md` 更新。

## 输出
验收记录、上线清单、回滚步骤、遗留风险与责任人。

## 门禁
- 没有未关闭的 P0/P1。
- 备份恢复与回滚至少演练一次。
- 生产默认配置不包含演示密钥或通配 CORS。

# Security Review

## 使用时机
涉及登录、令牌、权限、租户、外部模型、文件上传、删除、导出或部署配置时。

## 检查清单
- 是否存在默认密钥、通配 CORS、公开文档或调试接口。
- 认证方式、令牌过期、撤销、失败锁定与审计是否完整。
- 应用、用户、租户、知识库、文档权限是否最小化。
- 外部模型是否脱敏、是否可关闭、是否有降级与数据出境评估。
- 上传文件类型/大小、注入、SSRF、路径穿越是否防护。
- 日志、事件、导出和备份是否含敏感信息。
- 依赖漏洞、镜像基线、非 root、只读文件系统与网络策略。

## 输出
风险等级、阻断项、修复建议、验证命令与上线条件。

## 禁止
- 不得以“内网”为由跳过鉴权或审计。
- 不得把真实密钥写入仓库、镜像或示例。

# SDD Implement

## 使用时机
任务已拆分，需要落代码、测试或迁移时。

## 输入
`tasks.md`、相关代码、现有测试与配置约定。

## 步骤
1. 先读相邻代码与测试，沿用现有框架、命名和错误模型。
2. 先写最小失败测试，再实现；涉及契约先改契约。
3. 数据迁移必须可重复执行，并提供 downgrade 或回滚说明。
4. 每次改动后运行相关测试、ruff、mypy。
5. 更新文档、`.env.example`、部署清单与变更记录。

## 输出
代码、测试、迁移、配置和验证记录。

## 门禁
- 不引入未使用依赖或秘密。
- 新接口有鉴权、租户范围和审计。
- 全量 `bash scripts/gates/quality.sh` 通过。

## 禁止
- 不得用硬编码演示数据掩盖真实失败。
- 不得删除或弱化既有安全测试。

# RAG Design

## 使用时机
改动知识库、索引、召回、重排、压缩、引用或图谱检索时。

## 检查清单
- 文档切分是否保留条款、段落、页码与版本。
- 稠密/稀疏召回、RRF、重排权重是否有可复现配置。
- 引用 snippet 是否来自原文，chunk_id 是否稳定。
- 压缩是否保护法条、金额、日期、案号，并在校验失败时回退原文。
- GraphRAG 的实体/关系是否有来源与置信度。
- 是否有 Recall@K、引用准确率、延迟与成本评测。

## 输出
检索方案、参数、失败降级、评测集与验收指标。

## 禁止
- 不得用模型摘要替换原始引用。
- 不得在无引用校验时开启压缩。
